1. Vision Produit

Qu'est-ce que JADOMI ?

Plateforme SaaS B2B pour professionnels libéraux de santé (dentistes, prothésistes, médecins, kines...) et multi-secteurs (BTP, juridique, immobilier, commerce, créateurs, services, outils).

Mission : FOURNIR TOUT CE DONT GALERE UN CABINET pour gérer son activité, avec l'IA.

Positionnement stratégique

JADOMI n'est PAS un vendeur. JADOMI est L'OUTIL DE VENTE pour les autres (comme Stripe pour les paiements, Shopify pour les marchands, Doctolib pour les RDV). Zero conflit d'intérêt, scalable.

Promesse client

  • 42 000 professionnels de santé cibles en France
  • Economies garanties : ~1 840 EUR/an par cabinet
  • 0 gaspillage (JADOMI Green)
  • Plateforme multi-métiers adaptative

7. Decisions Stratégiques

  1. Vouvoiement premium partout -- Ton concierge 5 etoiles, zero emoji chatbot
  2. Chinese Wall DENTALEVOLUTION -- Fournisseur normal, zero favoritisme algorithmique
  3. 1 commande = 1 fournisseur -- Anti-pollution, simplicite UX
  4. Transparence asymetrique GPO -- Fournisseurs voient tarif cible, dentistes non
  5. Acquisition virale fournisseurs -- Via vraies commandes, pas pub
  6. Simplicite radicale UI -- IA decide, user choisit entre propositions
  7. Regle 150 EUR frais de port -- Gratuit si panier >= 150 EUR
  8. Groupon dentaire 48h / 5 cabinets min -- Double trigger + urgence
  9. UX unifiee 1 bouton 3 modes -- Simplifier radicalement
  10. Coach personnalise -- Onboarding adapté par profession
  11. Landings par métier > Landing mixte -- Conversion x3, stratégie Stripe/Shopify
  12. Segmentation respectueuse -- Kine =/= coiffeur. Paramedicaux distincts du bien-être
  13. Terminologie correcte -- Chirurgien-dentiste (pas dentiste)
  14. JADOMI Timeline = moat concurrentiel -- Feature killer, aucun SaaS dentaire FR ne proposé ca
  15. Zero nom propre réel -- Noms fictifs uniquement sur le site public
  16. Wizard simple, site dans dashboard -- Le wizard créé le compte (2 min). Le site = module payant premium.
  17. JADOMI Ads = régie verticale -- Double revenu, ciblage RPPS/ADELI, ROI x5 vs Facebook
  18. JADOMI Studio = marketplace IA verticale -- Orchestrateur APIs, moat 42k dentistes + prompts optimises + wallet
  19. Dogfooding premium -- Le site JADOMI doit être la vitrine ultime. Niveau Awwwards.
