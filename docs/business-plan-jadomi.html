JADOMI — Business Plan v2.0 — Confidentiel 2

1. Résumé exécutif

JADOMI est un écosystème SaaS multi-sectoriel qui transforme la gestion quotidienne des professionnels libéraux et indépendants. 7 secteurs, 21 modules, 8 sources de revenus — une plateforme unique qui répond aux besoins transversaux de tous les professionnels : achats groupés, facturation, sites vitrines, visio, gestion documentaire.

La vision

Les professionnels libéraux (dentistes, avocats, artisans BTP, commerçants, créateurs) partagent les mêmes problèmes : outils fragmentés, surcoûts sur les achats, absence de digitalisation, conformité réglementaire complexe. JADOMI unifie tout dans un écosystème modulaire, adapté par secteur mais partageant un socle technologique commun.

Les 7 secteurs adressés

  1. Dentaire — Achats groupés, comparateur prix, scanner IA, photo prothèses
  2. Avocats — Coffre-fort numérique, sites vitrines, gestion dossiers
  3. BTP / Artisans — Devis, facturation, achats matériaux groupés
  4. Paramédical — Kinés, infirmiers, orthophonistes : gestion cabinet
  5. Commerce de proximité — Site vitrine, fidélisation, commandes en ligne
  6. Créateurs / Freelances — Portfolio, facturation, gestion clients
  7. Vétérinaires — Achats, stocks, facturation (similaire au dentaire)

Les 21 modules

Comparateur de prix, GPO (achats groupés), Scanner IA de factures, Facturation Factur-X, Studio CMS (sites vitrines), Coffre-fort numérique, Visio intégrée, JADOMI Ads (annuaire sponsorisé), JADOMI Coins (gamification), Chatbot IA, Gestion de stock, Alertes prix, Photo IA produits, Gestion dossiers patients/clients, Dashboard analytics, Notifications temps réel, Marketplace fournisseurs, Signature électronique, Export comptable, Support prioritaire, API partenaires.

2.2 Problèmes identifiés par secteur

Dentaire

  • Aucune transparence prix — écarts de 15 à 40 % pour un même produit
  • Produits identiques sous marques différentes (x3 sur le prix)
  • Gestion stock manuelle (Excel ou cahier papier)
  • Facturation électronique obligatoire septembre 2026 — majorité non prêts
  • Doctolib inutile pour cabinets saturés (70 % refusent de nouveaux patients)

Avocats

  • Stockage de pièces sensibles non sécurisé (emails, WeTransfer)
  • Sites internet obsolètes ou inexistants pour 60 % des cabinets
  • Pas de plateforme de visio-consultation dédiée et sécurisée
  • Facturation manuelle sans conformité Factur-X

BTP / Artisans

  • Achats matériaux fragmentés, aucun pouvoir de négociation individuel
  • Devis et factures encore sur papier ou Word
  • Suivi chantier non digitalisé

Commerce & Créateurs

  • Sites vitrines coûteux (à partir de 2 000 € chez les agences web)
  • Aucune solution intégrée facturation + site + fidélisation
  • Outils multiples non interconnectés (Shopify + Stripe + Mailchimp...)

4. Stratégie commerciale

4.1 Phase 1 — Dentaires (0-6 mois)

Le fondateur, chirurgien-dentiste en exercice à Roubaix depuis 15 ans, lance le déploiement dans son propre secteur. Cette approche « eat your own dog food » garantit une adéquation produit-marché immédiate.

  • Cible : 50 cabinets dentaires en Hauts-de-France via le réseau professionnel direct
  • Canal : Démarchage personnel, démos sur site, groupes WhatsApp dentistes
  • Argument : « Économisez 1 840 €/an sans rien changer à vos habitudes »
  • Hook : Facturation électronique obligatoire sept. 2026 = urgence légale
  • Objectif : 50 cabinets actifs, validation du modèle économique
Avantage fondateur-utilisateur : Dr Bahmed utilise JADOMI au quotidien dans son propre cabinet. Chaque fonctionnalité est testée en conditions réelles avant d'être proposée aux clients. Ce positionnement « par un dentiste, pour les dentistes » crée une confiance immédiate.

4.2 Phase 2 — Avocats (6-12 mois)

Le secteur juridique est le deuxième marché cible, avec un besoin immédiat sur deux modules forts de JADOMI : le coffre-fort numérique et les sites vitrines CMS.

  • Cible : 150 cabinets d'avocats (barreau de Lille, puis national)
  • Canal : Partenariats barreaux, LinkedIn Ads ciblés, webinaires Factur-X
  • Produits phares : Coffre-fort sécurisé (pièces sensibles) + Studio CMS (site vitrine professionnel en 5 min)
  • Cross-sell : Visio sécurisée + Facturation Factur-X
  • Objectif : 20 cabinets actifs fin An 1, 150 fin An 2

4.3 Phase 3 — BTP + Commerce + Créateurs (12-24 mois)

Une fois le modèle validé sur deux verticales (dentaire + avocats), JADOMI ouvre simultanément trois nouveaux secteurs en réutilisant le socle technologique existant.

BTP / Artisans

  • Module clé : GPO matériaux (achats groupés ciment, bois, plomberie)
  • Canal : Fédérations d'artisans, chambres de métiers, salons pro
  • Objectif : 100 artisans actifs fin An 2

Commerce de proximité

  • Module clé : Studio CMS + JADOMI Coins (fidélisation clients)
  • Canal : CCI locales, associations de commerçants, Google Ads local
  • Objectif : 80 commerces actifs fin An 2

Créateurs / Freelances

  • Module clé : Studio CMS (portfolio) + Facturation + Signature électronique
  • Canal : Communautés en ligne, Malt, LinkedIn, co-workings
  • Objectif : 70 créateurs actifs fin An 2
