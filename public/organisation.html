Connexion boîte mail
JADOMI se connecte à votre boîte mail pour lire, classer et vous aider à répondre.
Comment connecter votre boîte mail ?
Gmail
  1. Connectez-vous sur myaccount.google.com
  2. Allez dans Sécurité
  3. Activez la Validation en 2 étapes si pas déjà fait
  4. Cherchez Mots de passe des applications
  5. Sélectionnez "Autre (nom personnalisé)" et tapez JADOMI
  6. Copiez le mot de passe de 16 caractères
  7. Collez ce mot de passe ci-dessous (pas votre mot de passe Gmail normal)
Le lien direct : myaccount.google.com/apppasswords
Outlook / Hotmail
  1. Connectez-vous sur account.microsoft.com
  2. Allez dans Sécurité
  3. Cliquez sur Options de sécurité avancées
  4. Section Mots de passe d'application puis Créer
  5. Nommez-le JADOMI et copiez le mot de passe généré
  6. Collez ce mot de passe ci-dessous
Si l'option n'apparaît pas : activez d'abord la vérification en 2 étapes
Yahoo Mail
  1. Activez l'IMAP : Yahoo Mail → Paramètres → Autres applis → Activer IMAP
  2. Connectez-vous sur login.yahoo.com
  3. Cliquez sur votre avatar puis Informations du compte
  4. Allez dans Sécurité du compte
  5. Cliquez sur Générer un mot de passe d'application
  6. Sélectionnez "Autre application" et tapez JADOMI
  7. Copiez le code de 16 caractères généré
  8. Collez ce code ci-dessous
OVH / Orange / Free / SFR / Laposte
  1. Utilisez directement votre mot de passe habituel
  2. Ces fournisseurs ne nécessitent pas de mot de passe d'application
  3. Si erreur : vérifiez que l'IMAP est activé dans les paramètres de votre messagerie
Autre fournisseur

Renseignez le serveur IMAP et le port (généralement 993 en SSL). Consultez la documentation de votre fournisseur pour les paramètres IMAP.
